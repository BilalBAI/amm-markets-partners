# Web3 Platform Engineer

## Mission

Turn AMM Markets protocol capabilities into reliable, clear, and verifiable wallet and LP workflows.

## Responsibilities

- Maintain the Web, API, and LP workspace.
- Build product features with React, TypeScript, Node.js, and viem.
- Support EOA, WalletConnect, Safe App, and institutional-wallet flows.
- Build unsigned transactions, previews, and confirmation experiences.
- Handle allowances, simulations, slippage, nonces, and transaction status.
- Work with the data engineer on markets, positions, depth, and fee displays.
- Maintain desktop, mobile, Safe-iframe, and wallet regression tests.

## Useful capabilities

- Strong React/TypeScript and practical Web3 product experience.
- Understands ABI, calldata, logs, receipts, RPC, and transaction lifecycles.
- Has used viem, ethers, Safe SDK, or WalletConnect.
- Can handle browser security, cross-origin requests, and error recovery.
- Can explain protocol and risk concepts clearly instead of only building screens.

## What we value

Working Web3 products, wallet integrations, transaction previews, and testable user flows matter more than degrees or a fixed career timeline.

## Boundaries

- Does not store user private keys.
- Does not blind-sign or broadcast on behalf of LPs.
- Does not define dynamic fees or Hook policy.
- Does not independently own authoritative historical-chain calculations.
