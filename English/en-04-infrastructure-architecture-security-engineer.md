# Infrastructure, Architecture & Security Engineer

## Mission

Create clear, secure, and recoverable operating boundaries between the website, data platform, and high-frequency on-chain systems, while guiding infrastructure evolution.

## Responsibilities

- Design the overall architecture for Web, RPC, data, high-frequency systems, and Ethereum nodes.
- Operate the independent website server, Linux, systemd, Nginx, TLS, DNS, and firewall.
- Design Hetzner, cloud, container, and future multi-region deployment paths.
- Establish CI/CD, releases, rollbacks, monitoring, logs, and alerting.
- Own IAM, SSH, MFA, secrets, certificates, and access reviews.
- Design backup, restore, RTO/RPO, disaster recovery, and failure exercises.
- Evaluate providers, RPC failover, capacity, performance, and cost.
- Drive threat modeling, secure development, and supply-chain security.

## Useful capabilities

- Can design and operate stateful production systems.
- Comfortable with Linux, networks, TLS, DNS, containers, and infrastructure as code.
- Has used Terraform, Ansible, Docker, Prometheus, Grafana, or OpenTelemetry.
- Has practical backup/restore, incident-response, and migration/rollback experience.
- Understands Ethereum RPC, execution/consensus clients, and wallet-security boundaries.
- Can make clear trade-offs between security, reliability, performance, and cost.

## What we value

Real production systems, failure exercises, migration plans, recovery records, and security designs matter more than certificates, degrees, or a fixed career timeline.

## Not owned by this role

- AMM fee or Hook policy.
- The only protocol audit.
- User private keys or Safeheron signing authority.
